# 📱 Sports Booking App (React Native)

## 📌 Overview
This is a cross-platform mobile application built with **React Native**, designed to connect **users** and **sports facility managers** on a single platform.

The application allows users to discover and book sports facilities easily, while managers can handle bookings, schedules, and payments efficiently.

---

## 🚀 Features

### 👤 User (Customer)
- Select favorite sports (football, badminton, tennis, etc.)
- Search for sports facilities by preference
- View detailed facility information
- Read and write reviews/ratings
- Book available time slots
- Manage booking history

---

### 🧑‍💼 Manager (Facility Owner)
- View booking requests from users
- Approve or reject reservations
- Manage schedules and availability
- Calculate and confirm payments
- Track booking activities

---

## 🛠️ Tech Stack
- **Framework:** React Native
- **State Management:** Redux / Context API
- **API:** RESTful APIs
- **UI:** TailwindCSS / Styled Components
- **Realtime (optional):** Firebase / WebSocket

---

## 🏗️ Architecture
- Clean and scalable project structure
- Separation of concerns (UI - Business Logic - API)
- Reusable components to improve development speed
- Role-based system (User & Manager)
